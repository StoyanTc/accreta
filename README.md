# accreta-ffi

C ABI wrapper for the [`accreta`](https://crates.io/crates/accreta) Rust library.

This version intentionally does **not** put the entire ABI in `src/lib.rs`.
The crate root only exposes the ABI surface; implementation is split into small
modules by responsibility.

## Source layout

```text
src/
├── lib.rs       # public ABI surface / re-exports
├── types.rs     # C-compatible types and opaque handles
├── support.rs   # unsafe-pointer, string, ownership, panic helpers
├── schema.rs    # schema builder functions
├── engine.rs    # engine lifecycle, ingest, rollup, prune
├── query.rs     # range queries and grouped-result lifecycle/access
├── aggregate.rs # aggregate state decoding
└── status.rs    # status and aggregate-name strings
```

The generated C header should remain the consumer-facing contract. Do not
hand-edit it.

## Rust 2024

This crate is designed for `edition = "2024"`. Rust 2024 requires unsafe
attributes such as `no_mangle` to be written explicitly as:

```rust
#[unsafe(no_mangle)]
pub extern "C" fn ...
```

The ABI uses that form throughout. See the Rust Edition Guide for the reason:
`no_mangle` changes the global symbol namespace and therefore has safety
requirements that the compiler cannot verify.

## ABI organization

### `types.rs`

Contains only the C-facing data model:

- `AccretaStr`
- `AccretaStatus`
- `AccretaMeasureType`
- `AccretaAggregateType`
- `AccretaBucketLevel`
- `AccretaValue`
- `AccretaValueUnion`
- `AccretaAggregateValue`
- opaque Rust handles

### `schema.rs`

Contains the schema construction API:

- create/free builder
- add dimensions
- add measures and built-in aggregates
- finalize schema
- inspect dimension/measure counts

### `engine.rs`

Contains the mutable engine API:

- create/free engine
- ingest
- rollup
- prune
- bucket counts

### `query.rs`

Contains query execution and query-result ownership:

- range query
- grouped range query
- grouped result iteration/access
- aggregate-set destruction

### `aggregate.rs`

Converts the concrete Rust aggregate states into one stable C representation.
`Average` is deliberately returned as its mergeable `(sum, count)` state rather
than as a precomputed floating-point result.

### `support.rs`

Keeps the unsafe mechanics out of the ABI functions as much as practical:

- raw pointer/count validation
- UTF-8 conversion
- ownership/destruction
- panic boundaries
- backing storage for `accreta`'s `&'static str` schema names

## Ownership

C owns no Rust allocation directly. Objects returned by the ABI must be
released using their corresponding `*_free` function.

The current `accreta::Schema` stores names as `&'static str`. The FFI therefore
owns the backing strings in the schema/engine handles. C callers only pass
borrowed `(ptr, len)` strings and do not need to keep them alive after the FFI
call returns.

Grouped-query aggregate-set pointers are borrowed from the grouped result and
remain valid only until that grouped result is freed.

## Error boundary

Operations that execute Rust logic are wrapped in a `catch_unwind` boundary so
Rust panics do not unwind through C. The ABI converts the main expected failure
classes into `AccretaStatus` values.

## Using the C ABI

The generated C header is the consumer-facing API. A C application needs:

- `include/accreta.h` — generated by `build.rs`/xbindgen;
- the native `accreta-ffi` library produced by `cargo build --release`;
- the C source code that calls the ABI.

A complete example is in [`examples/c`](examples/c). It uses CMake so the same
example can be built on Linux, macOS, and Windows.

### Build the Rust library

From the repository root:

```bash
cargo build --release
```

After this step, the release library is under `target/release` and the C header
should be available under `include/accreta.h`.

### Build the C example

```bash
cd examples/c
cmake -S . -B build
cmake --build build
```

On Windows with a multi-configuration generator:

```bash
cmake --build build --config Release
```

See [`examples/c/README.md`](examples/c/README.md) for the ABI details and
platform notes.
